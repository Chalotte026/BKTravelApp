# ⛩️ Bangkok Travel App (.NET MAUI) *** For Study only

**Bangkok Travel App** is a mobile application built using the **.NET MAUI** framework. It helps users discover attractions in Bangkok, search for locations near them, and navigate using native map applications.

## 🚀 Key Features
- **Location Filtering:** Browse locations by categories like Temples, Cafes, and Landmarks.
- **GPS & Geolocation:** Integrated **Geolocator API** to find and display tourist spots near the user's current position.
- **Native Map Launch:** One-click navigation that opens Apple Maps on iOS or Google Maps on Android.
- **Local Persistence:** Data is managed asynchronously using an **SQLite** local database.

## 🛠️ Technology Stack
- **Framework:** .NET MAUI (.NET 7/8)
- **Language:** C#
- **Database:** SQLite (sqlite-net-pcl)
- **UI:** XAML with MVVM Patterns
